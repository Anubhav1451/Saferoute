## 📊 Technical Stack Highlights

### Frontend
- **Next.js 15**: React framework with server components
- **Mapbox GL**: Interactive maps with 3D buildings
- **Framer Motion**: Smooth animations and transitions
- **Tailwind CSS**: Cyberpunk theme with neon effects

### Backend
- **FastAPI**: High-performance Python API
- **Machine Learning**: Scikit-learn safety prediction model
- **SQLite**: Local database for safety nodes and crime data
- **Real-time Processing**: Sub-second route calculations

### AI/ML
- **Random Forest Regressor**: Safety score prediction
- **Feature Engineering**: 15+ safety features
- **Confidence Scoring**: Model reliability metrics
- **Fallback Systems**: Rule-based when AI unavailable
