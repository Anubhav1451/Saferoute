# Review Guides Directory

This directory contains structured review guides and checklists for conducting thorough code reviews, architecture reviews, security reviews, and other technical reviews. These guides ensure consistent, thorough, and effective review processes across all skills developed using this framework.

## Review Guides

- **code-review-guide.md**: Comprehensive checklist for reviewing code quality, maintainability, adherence to standards, and best practices
- **architecture-review-guide.md**: Guidelines for reviewing system architecture, scalability, design patterns, and technology choices
- **security-review-guide.md**: Checklist for identifying security vulnerabilities, ensuring secure coding practices, and verifying security controls
- **performance-review-guide.md**: Guidelines for reviewing performance characteristics, identifying bottlenecks, and verifying optimization opportunities
- **database-review-guide.md**: Checklist for reviewing database design, schema quality, indexing strategies, and query performance
- **api-review-guide.md**: Guidelines for reviewing API design, documentation, error handling, security, and versioning
- **test-review-guide.md**: Checklist for reviewing test coverage, quality, effectiveness, and test maintenance practices
- **documentation-review-guide.md**: Guidelines for reviewing documentation completeness, accuracy, clarity, and usability
- **deployment-review-guide.md**: Checklist for reviewing deployment processes, configurations, rollback procedures, and environment parity

## Usage

Review guides should be used when conducting reviews of code, architecture, or other technical artifacts developed as part of skills following this framework. They help ensure comprehensive, consistent, and effective reviews that maintain quality standards.

Each review guide provides:
- Structured checklists organized by review category
- specific items to check with explanations of why they matter
- severity levels for findings (critical, high, medium, low)
- space for reviewer notes and recommendations
- references to relevant standards and best practices
