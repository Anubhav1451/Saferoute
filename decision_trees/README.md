# Decision Trees Directory

This directory contains decision trees and flowcharts that guide engineers through complex decision-making processes. These tools help ensure consistent, well-reasoned decisions across different skills and projects.

## Decision Trees

- **monolith-vs-microservices.md**: Guidance on choosing between monolithic and microservices architectures
- **technology-selection.md**: Framework for evaluating and selecting technologies
- **sql-vs-nosql.md**: Decision tree for choosing between SQL and NoSQL databases
- **cache-usage-decision-tree.md**: Guidelines for when and how to implement caching
- **queue-event-system-decision-tree.md**: Decision guide for message queues and event streaming platforms
- **api-versioning-decision-tree.md**: Strategies for API versioning and evolution
- **cloud-deployment-decision-tree.md**: Guidance on cloud deployment models and vendor selection
- **build-vs-buy-decision-tree.md**: Framework for build vs. buy decisions for software solutions

## Usage

Decision trees should be consulted when making significant technical decisions. They help ensure that all relevant factors are considered and that decisions align with organizational standards and best practices.
